# 项目库：外贸阀门工厂官网改造获客战役 v0.1

项目状态：已立项
立项日期：2026-05-17
项目类型：垂直赛道获客战役
所属业务：外贸独立站诊断与旧站改造

## 1. 项目定位

本项目是一人公司第一期垂直赛道获客战役。

目标不是先做完整建站系统，而是通过外贸阀门工厂落地页 demo 和旧网站诊断方案，获取 3-5 个诊断意向，并推进旧站改造机会。

本目录不是长期资产仓库，而是本战役的项目档案。

执行过程中产生的 demo、诊断方案、话术、客户名单、报价模板等，可先临时放在本目录下；未来如果建立独立资产库或 GitHub repo，应迁移过去，并在本项目库中保留链接。

## 5. 当前阶段目标

- 形成至少 3 套标杆级外贸阀门工厂 demo 网站模板，达到客户展示级视觉设计、基础交互体验、移动端适配和行业可信表达。
- 形成可用于客户沟通的官网诊断方案。
- 建立一批可触达的潜在客户名单。
- 获取 3-5 个诊断意向。
- 推进至少 1 个旧站改造报价机会。

## 6. 项目边界

当前阶段暂不做：

- 内贸阀门工厂
- 泛制造业全行业扩张
- 自研公司管理系统
- 复杂自动化销售系统
- 大规模内容 SEO

本项目先验证一个问题：

> 外贸阀门工厂是否愿意因为旧网站影响询盘，而接受诊断并考虑改造。
