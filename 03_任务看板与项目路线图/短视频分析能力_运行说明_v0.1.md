# 短视频分析能力（拆帧方案）v0.1

## 目标输出
- script_summary（脚本/内容概要）
- topic（视频在讲什么）
- visual_style（画风、构图、色彩）
- quality_notes（画质、清晰度、压缩痕迹、节奏）
- prompt_candidates（可复用生成提示词）

## 当前可用链路
1. 用 `video_analyze_frames.py` 读取视频元信息并拆帧。
2. 对抽出的关键帧调用 `vision_analyze` 获取逐帧描述。
3. 汇总逐帧描述 + 元信息，产出结构化结论。

## 命令
```bash
python C:/Users/hp/.hermes/profiles/thoth_sec/scripts/video_analyze_frames.py \
  --video /c/Users/hp/tmp/short_test.mp4 \
  --out-dir /c/Users/hp/tmp/frames \
  --fps 0.5
```

## 备注
- Hermes 内置 `video_analyze` 已启用，但在本地/私网视频源上存在识别不稳定，故当前以拆帧方案作为稳定可用路径。
- 若后续提供可公网访问的视频直链，可优先再测 `video_analyze` 直读能力。
