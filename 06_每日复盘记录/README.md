# 每日复盘记录

本目录用于存放董事会层面的每日收盘复盘档案。

每日收盘审计与复盘整理任务应按日期生成：

```text
YYYY-MM-DD_每日收盘复盘.md
```

单日复盘记录只沉淀可见证据，不补全、不虚构、不替执行层做未上报判断。

固定内容包括：

- 今日完成
- 文件与文档变动
- 审计发现
- 清理处理
- 重要文件提醒
- 董事长每日战情简报
- 风险与阻塞
- 明日建议
- 自动化留痕
- 未归档事项

所有日终自动化都必须留下可追踪记录：

- cron 类任务应写入当日复盘档案的“自动化留痕”部分。
- 董事长每日战情简报属于正式公司账册，应由 cron 写入当日复盘档案。
- 心跳类任务只用于提醒或回访；若内容具有复盘、审计、战情或决策价值，应转为 cron 存档。
- 留痕只记录真实执行结果、跳过项和风险，不为了凑记录制造内容。
