# 董事会第 2 号决议：外贸阀门工厂官网改造获客战役 v0.1

日期：2026-05-17
状态：已通过
决议编号：董事会第 2 号决议（编号校正）
决议级别：阶段性经营决策
归档位置：董事会决议
尺度审计：战役级，通过。董事会确认方向、目标、边界、授权和验收口径，不直接拆解执行任务或项目 Kanban。
编号说明：本决议原为公司首个业务战役决议。2026-05-18 经董事会校正，《OA 系统、Hermes Agent 系统与 Holographic Memory v0.1》列为董事会第 1 号决议，本决议顺延为董事会第 2 号决议，并在第 1 号决议框架下接入执行。

## 1. 决议名称

本期战役正式命名为：

> 外贸阀门工厂官网改造获客战役 v0.1

该事项归类为公司第一期垂直赛道获客战役。

## 2. 决策背景

公司现阶段需要用一个足够具体、可诊断、可展示、可报价的垂直场景，验证“一人公司官网改造获客服务”的商业切入能力。

董事会判断，外贸阀门工厂具备以下特征：

- 依赖官网建立海外买家信任。
- 旧网站问题通常可被诊断、展示和转化为改造需求。
- 客户价值判断相对明确，适合用样板资产和诊断方案打开沟通。
- 赛道足够垂直，适合进行第一轮验证。

## 3. 董事会目标

本阶段目标：

> 获取 3-5 个外贸阀门工厂旧网站诊断意向，并从中推进旧网站改造报价机会。

本目标是阶段性经营验证目标，不是长期战略承诺。

董事会关注的是：

- 该赛道是否值得继续投入。
- 样板资产是否足以支撑客户沟通。
- 诊断方案是否能引发真实需求。
- 是否存在过度承诺、资源过载或方向漂移。

## 4. 授权范围

董事会授权 Hermes CEO Agent 在本决议范围内组织执行团队，进行研究、方案设计、样板制作、客户筛选、触达测试和阶段复盘。

CEO Agent 可自行决定：

- 执行团队的具体分工和调度方式。
- 任务拆解、项目 Kanban 和执行节奏。
- 市场研究方法和样本选择方式。
- demo 类型、页面结构和视觉表达方向。
- 诊断方案结构、客户名单筛选口径和触达话术版本。
- 内部质量检查和阶段性交付安排。

董事会不预设具体 Agent 编制、设计风格、客户细分、页面结构、话术版本或日常排期。上述事项属于 CEO 团队的经营执行权限。

## 5. 边界与不做事项

本阶段暂不做：

- 内贸阀门工厂官网。
- 泛制造业全行业扩张。
- 自研公司管理系统。
- 复杂 CRM / SaaS 平台。
- 大规模内容 SEO。
- 保证询盘增长的效果承诺。
- 超出官网诊断与改造获客验证范围的长期运营托管。

所有对外表达必须保持专业、克制、可信，不得用未经验证的数据、案例或结果承诺包装服务。

## 6. 验收口径

本阶段以实质成果验收：

- 形成至少 3 套客户展示级外贸阀门工厂 demo 网站样板。
- 形成可用于客户沟通的旧网站诊断方案。
- 建立一批可触达的潜在客户名单。
- 获得 3-5 个诊断意向。
- 至少推进 1 个旧网站改造报价机会。

董事会只验收结果、关键判断和风险，不验收内部任务清单、日常排期或 Agent 调用细节。

## 7. 样板资产质量红线

本战役 demo 不是草稿、线框图、默认模板或仅能交互的原型，而是获客用样板资产。

3 套 demo 必须达到：

- 可直接向潜在客户展示，不需要解释“这只是草稿”。
- 视觉完成度、页面结构和英文表达达到专业 B2B 官网水准。
- 保留工业品采购判断所需的可信度，不追求脱离行业语境的炫技设计。
- 覆盖产品、工厂实力、质量控制、认证/标准、应用行业和询盘入口。
- 具备基础交互体验，包括导航、CTA、产品模块、RFQ 入口、表单入口和响应式行为。
- 每套 demo 有清晰类型定位、样本依据和适用客户说明。

质量红线：

- 不接受低保真草稿。
- 不接受通用机械模板简单换字。
- 不接受只有交互、没有完整视觉设计。
- 不接受看起来漂亮但不服务海外采购判断和诊断转化。
- 不接受保证询盘增长等过度承诺。

## 8. 首次董事会回报要求

CEO 团队接收本决议后，首次回报应提交董事会需要判断的实质成果，而不是内部 Kanban 或任务分配细节。

首次回报应包括：

- 3 套客户展示级 demo 网站样板。
- 每套 demo 的类型定位、样本依据和适用客户说明。
- 旧网站诊断方案初稿或框架。
- 首批潜在客户筛选口径。
- 当前关键判断、风险与卡点。
- 需要董事会拍板的问题。

董事会审核重点：

- 是否符合本阶段目标。
- 是否守住赛道与服务边界。
- 是否能够推进客户诊断意向。
- 是否存在过度承诺、资源过载或方向漂移。

## 9. 必须提交董事会确认的事项

以下情况必须提交董事会确认：

- 调整本战役目标。
- 改变垂直赛道边界。
- 涉及核心执行角色的设立、取消、重组，或可能改变战役目标、交付标准、资源投入、客户承诺和公司风险。
- 承接第一个付费改造客户。
- 对客户作出重大结果承诺、交付承诺或价格承诺。
- 需要新增明显资源投入。
- 出现影响公司信誉、现金流或客户关系的重大风险。

## 10. 复盘节点

建议在以下节点进行董事会复盘：

- CEO 提交第一轮 3 套 demo 网站样板后。
- 第一份诊断方案完成后。
- 拿到第一个真实诊断意向后。
- 推进第一个旧站改造报价后。
